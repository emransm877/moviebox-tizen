# MovieBox Samsung TV 0.9.3

20 themes, animated poster browsing, a consistent sidebar and compact Continue
watching cards bring a cleaner interface to the big screen. Existing playback,
saved titles, episode progress and subtitle/audio preferences remain available.

- Keep artwork attached to its own title and fill equal catalogue frames
  proportionally. Retain catalogue position and remote focus during loading.
- Remove repeated hero covers; resume automatic browsing eight seconds after
  remote input. Select a poster to open that title's details.
- Add the semi-transparent right-side episode panel, fitting between the player
  bars with fixed header/footer and a scrolling list of actual episodes.
- Repair double-encoded punctuation while preserving international text.
  Improve task isolation, source recovery, Settings navigation and fitted menus.

## Installation

Download `MovieBox-TV-0.9.3-install-bundle.zip`, extract it and read `INSTALL-TV.md`.
The bundle contains the unsigned widget and Windows signing/install helper.
Samsung developer installation requires Tizen Studio, the Samsung TV extensions
and a certificate authorized for your TV. This is not a universal one-click TV
installer or a Samsung Store package. The separately supplied unsigned WGT is
for the same developer workflow; it cannot install without valid signing.

## Validation and limits

The exact widget was installed in place on the Samsung U8000F running Tizen 10.
Checks covered actual decoded 1080p playback/pause, episode-panel geometry,
title-bound artwork, deduplication, automatic browsing recovery and preserved
library data. Earlier hardware checks cover Tizen 9. The final combined source
passed 19 browser suites and 24 Node tests, plus installer/bundle checks.
Injected remote-key checks do not establish physical IR latency or a universal
frame-rate guarantee. Minimum target is Tizen 7; other models and future firmware
need their own validation. Media availability remains dependent on the service.

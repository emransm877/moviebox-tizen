# MovieBox Samsung TV 0.9.3

Start with INSTALL-TV.md, then run Install-MovieBoxTV.cmd on your Windows PC.
Your Samsung TV needs Developer Mode and an authorized Samsung signing profile.
Keep the widget, checksum and both helper files together after extraction.

See RELEASE-NOTES.md for the new interface and the exact validation scope.
The unsigned widget in this bundle has the same reviewed bytes as the separate
MovieBox-TV-0.9.3-unsigned.wgt download. No device certificate or private key is
included. Your saved library is outside the package and is preserved by an
in-place update with the same application author identity.

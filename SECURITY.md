# Security

Use GitHub private vulnerability reporting for credential or exploit reports.
Do not share signing keys, certificate passwords, DUIDs or account sessions in
public issues. Security changes target the current development source.

The installed app makes its own service requests. Its protocol constant is
shared public client metadata, not an account credential or a TV signing key.
The optional browser preview binds to loopback and does not accept arbitrary
subtitle-proxy hosts or arbitrary method names.
